HKDSE ICT (2025+) 官方 SQL、ERD 與 3NF 速查表

        
      

      

        

          
1. 子句邏輯執行次序

          
1.FROM → 2.JOIN → 3.WHERE → 4.GROUP BY → 5.HAVING → 6.SELECT → 7.ORDER BY

          
WHERE 分組前篩行；HAVING 分組後篩組。

        

        

          
2. 運算符與 SQL-92 防伏

          
+ - * / | = <> > < >= <= | AND OR NOT

          
LIKE '%' (任意字元) / '_' (單一字元) — 切勿用 '*'！

          
BETWEEN | IN / NOT IN | IS NULL / IS NOT NULL

        

        

          
3. 正規化 1NF / 2NF / 3NF 口訣

          
1NF：每格單一原子值（無重複組 Repeating Group）

          
2NF：已達 1NF ＋ 消除部分依賴（非主鍵須依賴整個複合主鍵）

          
3NF：已達 2NF ＋ 消除傳遞依賴（非主鍵不可依賴另一非主鍵）

        

        

          
4. ERD 符號（C&A Guide p.41）

          
長方形：Entity｜菱形：Relationship｜底線橢圓：Key Attribute

          
基數：1:1, 1:M, M:N｜雙線：Mandatory｜單線：Optional
